# Milestones

合意した達成目標・範囲・完了条件は
[GitHub Milestones](https://github.com/im-backgrounds/scratchlab/milestones)を正本とします。
作業の状態・優先度と未確約候補は
[ScratchLab Development](https://github.com/users/im-backgrounds/projects/3)で管理します。

Milestoneは期限やリリース提供の約束ではありません。
選択・作成・割当は[GitHub Workflow](github-workflow.md#milestone-assignment)に従います。
Prototype Modeは[Copilot指示](../.github/copilot-instructions.md)を既定とし、
Stabilization/Releaseへの変更には明示的な合意が必要です。

旧バージョン案は[履歴](releases/planning-baseline-2026-10.md#旧バージョン目標の扱い)、
各記述の移行先は[移行対応表](planning-migration.md)を参照してください。
ここにGitHubの作業一覧や進捗を複製しません。
