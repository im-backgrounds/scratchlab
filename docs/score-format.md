# 譜面データ

譜面ファイルはJSONで記述する。JSONコメントと末尾カンマは使用しない。

## 符号

- 符号
  - F: 前進
  - B: 後進
  - `-`: 直前の方向のまま連続で音を出す
  - K: キープ（水平線で前後を接続）
- 修飾記号
  - O: フェーダOFF→ON（開く）
  - M: フェーダON→OFF（閉じる）
  - C: チョップ（1回のフェーダーカット）
  - F: フレア（1回のフェーダーカット）
- Cは1音だけ鳴らして区間後半をミュートする。Fは区間冒頭の短い無音の後、カット後の音を一度だけ鳴らして終端まで伸ばし、通常のF/Bと同様にフェードする。
- Fの直後に同じ方向の修飾なしF/Bまたは`-`が続く場合、後ろの音は連続する区間まで伸びる。Kは伸長を止める区切りとして扱う。
- Kは修飾記号ではなく単独の符号で、水平線を描いて隣接する譜線を接続する。K区間はスクラッチ音を出さず、直前のスクラッチ音の余韻も区間開始時に止める。クリック音は通常どおり鳴らす。リズム譜では休符として表示し、フェーダー状態は変更せず、前後の符号の再生に影響しない。同じ向きの符号の間にあるKは、個数が1つでも複数でも同じ方法で扱う。斜線の傾きはKを除いた符号間の時間幅で計算し、Kが占める時間幅は含めない。各Kの高さは、Kを除いた最も近い前の符号の終点の高さにする。前後の符号の向きは高さの判定に使わない。Kに修飾記号を付けることはできない。
- 初期状態はフェーダーON。修飾記号を省略した符号は現在のフェーダー状態を維持する。
- OはOFFからONへ開く位置、MはONからOFFへ閉じる位置に記載する。
- 符号末尾の正の整数は、その符号を割り当てられた時間内で均等に繰り返す回数（実装上は1〜128）。
- 分割が1小節768セルを超えるデータは読み込めない。

## 符号の書式

- 書式: `{方向}{修飾記号}{繰り返し回数}` または `K{繰り返し回数}`
- 例: `FF`は前進フレア、`BM`は後進ミュート、`K`はキープ、`BC3`は割り当て時間内に後進チョップを3回。
- `K`は単独の符号であり、`FK`や`BK`のように修飾記号を付けることはできない。`K3`は割り当て時間内にキープを3回行う。
- `-`は方向符号ではなく、直前の方向とフェーダーON状態を継続する。

## 譜面データルール

- `name`: 譜面名
- `difficulty`: `Easy`、`Medium`、`Hard`
- `beat`: 拍子。例: `4/4`
- `score`: 小節の配列。配列の各要素が1小節。
- 小節要素が符号文字列なら、その符号を小節全体に適用する。
- 小節要素が配列なら、配列要素数で小節を均等分割して適用する。入れ子配列は割り当てられた区間をさらに均等分割する。
- 符号の数値リピートも、符号に割り当てられた区間を均等分割する。
- `M`の区間は時間を占めるが、音と斜線は表示しない。

## データ例

### Baby Scratch

```json
{
  "name": "Baby Scratch",
  "difficulty": "Easy",
  "beat": "4/4",
  "score": [
    "F",
    "B",
    ["F", "B"],
    ["F", "B", "F", "B"]
  ]
}
```

各スコア要素は1小節。最初の小節は前進を4拍、次は後進を4拍、3つ目は前進・後進を各2拍、最後は前進・後進を各1拍で行う。

### Forward Scratch

```json
{
  "name": "Forward Scratch",
  "difficulty": "Easy",
  "beat": "4/4",
  "score": [
    ["FF", "BM"],
    ["FO", "BM", "FO", "BM"]
  ]
}
```

各小節で、前進フレアと後進ミュートを交互に行う。後進ミュートも時間区間として数える。

### Nested Subdivision

```json
{
  "name": "Hard Scratch",
  "difficulty": "Hard",
  "beat": "4/4",
  "score": [
    ["FF", ["BC", "-", "BC"], "FF", "BC3"],
    ["FF", "BM", "FO", "FM"]
  ]
}
```

入れ子配列は3連分割を表す。`-`は同じ方向の連続音、`BC3`はその区間を3分割した後進チョップ。
