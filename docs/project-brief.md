# 作りたいもの

## 概要

DJスクラッチ練習用のwebサービス。 html +
javascript(native)で動くシンプルな機能。

## 機能

- 左メニューから任意のDJスクラッチ譜面を選べる
  - 有名なスクラッチ練習ページリンクを難易度別でリスト表示
  - スクラッチ譜面の作成ページリンク
- 有名なスクラッチ練習ページ
  - スクラッチ譜面の表示
  - サンプルの再生
    - サンプルの音はjavascriptで生成
    - 再生BPMの変更
    - リピート再生
    - ボリューム変更
    - クリック音
      - ON/OFF
      - ボリューム変更
  - midi入力
    - DJコントローラの入力を記録
    - 記録とスクラッチ譜面との比較
    - 最大10リピートを記録
- スクラッチ譜面の作成
  - 有名なスクラッチ練習ページと同じ機能を持つ
  - 生成する小節の長さ変更
  - ランダム生成
    - スクラッチ譜面をランダム生成
  - MIDI生成
    - DJコントローラの入力を記録
    - 4カウント後に記録開始
  - 手動生成
    - 手動で記譜
  - スクラッチ譜面データのインポート
    - スクラッチ譜面ファイルをインポート
  - スクラッチ譜面の保存
    - スクラッチ譜面ファイルをエクスポート
    - 画像で保存
