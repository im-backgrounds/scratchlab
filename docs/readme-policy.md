# README 更新ポリシー

READMEは、利用者がアプリを理解し、セットアップして使うための案内です。
変更の影響を確認し、次の場合は実装と同じPRでREADMEを更新してください。

- 新機能の追加
- 利用者に見えるUIまたは操作方法の変更
- 利用者向け設定の変更
- 依存ライブラリの追加、削除、変更
- 環境構築や実行手順の変更

更新時は、変更された利用者向けの挙動・設定・前提条件だけを簡潔に反映し、
実装詳細や未提供のロードマップ候補は記載しないでください。
内部実装のみの変更などREADME更新が不要な場合も、IssueまたはPRで理由を明記します。

PRではREADME更新要否を必ず確認してください。関連する優先度・マイルストーン・
プロジェクト状況は`docs/roadmap.md`、追跡中の実装・検証作業は`docs/tasks.md`も
別途確認します。
