          SCRATCH NOTATION

          譜面の読み方

          はじめてでも大丈夫。譜面は「いつ」「どちらへ動かすか」「音を出すか」を、左から右へ読めるようにできています。

          まずはここだけ

          譜面は左から右へ読みます

          横の位置が時間です。再生すると左端から進みます。線の向きでレコードを動かす方向を、線や記号で音の出し方を確認します。

          1

          まず線の向きを見ます

          F は前進、つまり手前から奥へ押す動き。B は後進、奥から手前へ戻す動きです。譜面の上向き線がF、下向き線がBです。同じ向きの動きが続くと、線はつながって見えます。

          2

          横棒でフェーダーの操作を見ます

          譜面上の短い横棒は、フェーダーを切り替える位置です。O は閉じた状態から開く、M は開いた状態から閉じる合図です。最初はONで、修飾記号のないF・Bはフェーダーの状態を保ちます。再生中は緑がON、橙がOFFを表します。

          3

          1つの区間にかかる時間を見ます

          小節の中は均等に分けられます。配列の区切りが増えると、1つずつの区間は短くなります。入れ子の区切りは、その区間をさらに分けます。

          ["F", "B", "F", "B"] 4つの動きを同じ長さで行う
          ["F", ["B", "B", "B"]] 前進のあと、残りの時間を後進3つに均等分割

          よく使う記号

          記号は「方向」と「フェーダー操作」を組み合わせて読みます。たとえば FC は「前進しながらチョップ」です。

          記号 読み方 動きと音
          F / B 前進 / 後進 フェーダーの状態を保ったまま、矢印の向きに動かします。
          FO / BO フェーダーを開いて動く OFFからONに切り替え、その区間で音を出します。
          FM / BM フェーダーを閉じて動く ONからOFFに切り替えます。時間は進みますが、音と斜線は表示されません。
          FC / BC チョップ 1回音を出し、残りの区間はミュートします。
          FF / BF フレア 短く音を切ってから再び開き、1音を区間の終わりまで伸ばします。
          K キープ 音を出さずに水平線でつなぎます。再生中のスクラッチ音はKの開始時に止まりますが、クリック音は続きます。
          FC3 など 回数 末尾の数字は、その区間を均等に分けて繰り返す回数です。FC3 は前進チョップを3回行います。

          Kは単独で使う記号です。方向を表す符号に付けて FK や BK とは書きません。

          音が出ない区間も時間に含まれます

          M は音を止める区間です。斜線が描かれなくても、その区間の時間は進みます。動きを止める記号ではありません。

          再生しながら少しずつ練習

          1. 譜面一覧から練習したいパターンを選びます。
          2. 「再生」を押し、クリック音に合わせて譜面を目で追います。
          3. 難しければBPMを下げ、FとBの向きだけを先に練習します。
          4. 慣れたらフェーダー記号やC・F・Kの違いを加えます。
